황혼기록 · THE TWILIGHT ARCHIVE

실행
- 이 디렉터리에서 python3 -m http.server 8000 --bind 0.0.0.0 실행.
- 브라우저로 index.html, 편집은 admin.html에 접속합니다.
- 정적 호스팅에 index.html, admin.html, config.json, config-utils.js,
  refinements.css를 같은 디렉터리에 배치하세요. 런타임 npm 의존성은 없습니다.

대문
- 클릭이나 소리 재생 권한 없이 사진 회상이 자동으로 시작됩니다.
- 기본 장면 길이는 3.2초. 마지막 장면을 끝까지 보여 준 뒤 자동 입장합니다.
- 자동 재생 중 우측 위쪽 회전 손잡이로 4배 빠른감기를 켜고 끌 수 있습니다.
- 우측 아래쪽 회전 손잡이를 누르면 바로 입장합니다. 내부의 EJECT TAPE는 정상 속도로 처음부터 자동 재생합니다.
- 사진이 없거나 불러오지 못하면 황혼 필름 화면과 자막을 표시합니다.
- 장면을 모두 삭제하면 바로 내부로 입장합니다.
- 모션 감소 환경에서는 흔들림/노이즈 애니메이션을 끄고 자동 전환은 유지합니다.
- 이것은 사진 기반의 무음 VHS 회상 시퀀스이며 동영상 파일은 생성하지 않습니다.

편집과 보존
- 관리자 > 대문에서 모든 장면의 사진, 제목, 설명, 순서, 기본 재생 시간을 편집합니다.
- ↑/↓로 순서를 바꾸며 장면을 추가·삭제할 수 있습니다.
- 기존 label 형식 자막도 지원하며 알려지지 않은 설정 필드도 보존합니다.
- 기존 config.json 내용과 5개 회상 장면, 6개 카테고리를 유지했습니다.
- SAVE IN THIS BROWSER와 OPEN PREVIEW는 현재 설정을 동일 출처 브라우저에 저장합니다.
  홈페이지는 이 로컬 초안을 우선 사용하며 없으면 공개 config.json을 읽습니다.
- 공개된 config.json을 새로 편집하려면 해당 파일을 관리자에서 가져오세요.
- 방문자에게 공개하려면 DOWNLOAD CONFIG.JSON으로 내보내 서버의 config.json을 교체하세요.
- 관리자 페이지는 기존과 같은 정적 설정 편집기이며 서버 인증이나 공유 DB가 없습니다.
- 이미지가 커서 저장 공간이 부족하면 오류를 표시하고 기존 저장값은 유지합니다.
  사진은 웹용으로 축소하거나 JSON으로 다운로드하세요.
- 가져오기/JSON 적용 시 잘못된 구조는 거부합니다. 편집 전 JSON 백업을 권장합니다.

검증
- Node.js와 Chromium이 있는 환경에서 npm ci 후 서버를 실행하고 npm test.
- Chromium 위치가 다르면 CHROMIUM_PATH를 지정합니다.
- 브라우저 테스트: 자동 재생/장면 순서/자동 입장/재생 재시작,
  카테고리 탐색, 장면 편집/순서/추가/삭제, 사진 업로드, 설정 내보내기와 미리보기,
  320/390px 모바일 넘침, 구형 자막, 누락 사진/설정, 빈 장면, 모션 감소.
- 추가 검증: 4배속 시간, 속도 토글, 키보드 조작, 건너뛰기 후 타이머 정리,
  재입장 시 속도 초기화, 모바일 우측 조작부와 모션 감소 설정.
- 테스트 스크린샷은 artifacts/에 생성됩니다.
