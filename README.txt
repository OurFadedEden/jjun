황혼기록 · THE TWILIGHT ARCHIVE

실행과 나루 반영
- 이 폴더에서 python3 -m http.server 8000 --bind 0.0.0.0 실행.
- index.html이 홈페이지, admin.html이 편집실입니다.
- 같은 폴더에 필요한 파일:
  index.html, admin.html, config.json, config-utils.js,
  refinements.css, daylight.css, station.js, admin-station.js
- 최초 업그레이드 때 위 파일을 함께 올립니다. 기존 config.json은 먼저 백업하세요.
- 이후 글/사진/날짜/색상/음악 경로/교신 기록 변경은 관리자에서 설정을 편집한 뒤
  DOWNLOAD CONFIG.JSON으로 내려받아 공개 config.json만 교체합니다.
- 개인 사진, 음악 경로에 사용하는 파일은 해당 상대 경로에 함께 업로드합니다.
- 나루의 JSON/JS/음악 파일 호스팅 지원 여부는 실제 배포 환경에서 확인해야 합니다.
  이 프로젝트는 표준 정적 HTTP 서버에서 검증했습니다.

기존 데이터 보존
- 관리자에서 기존 config.json을 가져오면 새 위젯 기본 설정이 보완됩니다.
- 기존 회상 장면/카테고리/사진/문구와 알 수 없는 설정 필드는 보존합니다.
- 홈페이지와 관리자는 같은 출처의 twilightArchiveConfig 브라우저 초안을 우선 읽습니다.
  초안이 없으면 공개 config.json, 그것도 없으면 내장 기본값을 사용합니다.
- 공개 설정을 확인하려면 초안이 없는 다른 브라우저나 비공개 창에서 접속하세요.
- 이번 기본 색상은 황혼 #FAEDA5, 심해의 하늘빛 #A5D4FA입니다.
  TV와 전체 배경도 밝은 크림·하늘색이고 본문은 어두운 글자입니다.
  이전 기본 어두운 팔레트만 자동 전환하며 직접 지정한 색상은 보존합니다.
  관리자 색상 탭의 '밝은 황혼 × 하늘 팔레트 적용'은 전체 팔레트를 적용합니다.
- SAVE IN THIS BROWSER / OPEN PREVIEW는 이 브라우저에만 저장합니다.
  사이트 전체에 반영하려면 JSON을 내보내 공개 파일을 교체하세요.
- 사진이 너무 커서 브라우저 저장 한도를 넘으면 JSON 다운로드로 보관하세요.
- 관리자는 정적 파일 편집기이며 서버 로그인이나 비공개 저장소가 아닙니다.

대문
- 기존 브라운관 대문, 자동 회상 재생과 마지막 장면 후 자동 입장을 유지합니다.
- 위 회전 손잡이: 정상/4배속 전환. 아래 손잡이: 바로 입장.
- 내부 EJECT TAPE: 정상 속도로 처음부터 다시 재생.
- 기본 장면 길이 3.2초. 관리자에서 사진/제목/설명/순서/길이를 편집할 수 있습니다.
- 빈 사진이나 누락된 사진은 황혼 필름 화면으로 대체됩니다.
- 사진 배경 블러는 관리자에서 켜고 끌 수 있습니다. 장면이 없으면 바로 입장합니다.
- 모션 감소 환경에서는 장식 애니메이션을 끕니다. 자동 전환은 유지합니다.

고정 관측소
- 바깥 프레임과 상하단은 고정, 좌측 메뉴/세로 계기와 본문은 독립적으로 스크롤합니다.
- 모바일 카테고리는 상단 메뉴 버튼으로 여는 좌측 서랍입니다. 본문은 전체 너비를 사용합니다.
- 모바일 관측 계기는 본문 위 펼침 패널에, 대화 기록은 그 아래 열린 상태로 표시합니다.
- 발췌 사이트 sonar-main에서 좌표 격자, 등록 표식, 이중선, 눈금과 스탬프의 컨셉을 참고했습니다.
- 장식/격자/스탬프/여백 문구/프레임을 관리자에서 바꿀 수 있습니다.
- 공명·파형은 세계관을 위한 장식이며 실제 인물 상태 측정값이 아닙니다.
- 인물별 센티넬/가이드 역할은 임의로 지정하지 않습니다.

수심 디데이
- 기본 기준일 2025-09-30, 시작일 1일째. 기본 시간대 Asia/Seoul.
- 날짜가 하루 지날 때 1씩 증가하며 수심처럼 표시합니다.
- 기준 날짜, 기념일 이름, 단위, 뒤 문구, 시간대, 시작일 포함 여부를 관리자에서 수정합니다.
- 시작 전에는 남은 날짜를 표시하며, 날짜가 바뀌면 최대 1분 내 갱신합니다.
- 잘못된 날짜와 시간대는 가져오기/내보내기/저장할 때 거부합니다.

BGM
- 관리자 > 계기·BGM·교신 > 배경음악에 music/theme.mp3 같은 상대 경로나
  HTTPS 음원 주소 또는 YouTube 영상 링크를 같은 입력란에 넣습니다. 음악 파일은 따로 업로드해야 합니다.
- BGM은 제목 옆 상단 헤더에 표시됩니다. YouTube 링크는 사이트 안의 영상 플레이어로 재생합니다.
- YouTube 재생 버튼은 플레이어를 열고 재생을 요청합니다. 정지는 플레이어를 제거합니다.
  음량은 영상 자체 컨트롤로 조절합니다. 임베드 제한 영상에는 YouTube에서 열기 링크를 제공합니다.
- 곡 이름, 기본 음량, 반복 재생, 버튼과 상태 문구, 표시 여부를 수정할 수 있습니다.
- 방문자가 재생을 눌러야 소리가 납니다. 자동으로 소리를 재생하지 않습니다.
- 대문/카테고리 이동 중에는 음악이 이어집니다. 홈페이지를 새로 열면 다시 눌러야 합니다.
- 음원이 없으면 재생 버튼을 비활성화하고 안내 문구를 표시합니다.
- 누락되거나 지원하지 않는 파일은 오류 문구를 보여 줍니다.
- 프로젝트에는 사용자가 제공한 BGM 파일이 아직 없습니다.

대화 기록
- 관리자 작성형 두 사람의 교신 기록입니다. 실시간 채팅이나 비공개 메시지가 아닙니다.
- 발신자, 본문, 날짜/시간, 좌우 배치, 순서를 편집하고 추가/삭제할 수 있습니다.
- 기록은 JSON에 포함되어 방문자에게 공개됩니다.

글과 카테고리
- 제목, 본문, 사진, 소개, 타임라인, 링크, 회상 장면을 편집할 수 있습니다.
- 카테고리와 항목의 추가/삭제/순서 변경을 지원합니다. 마지막 카테고리는 삭제하지 않습니다.
- 내부 구조용 ID는 자동 생성하며 편집 화면에서는 변경하지 않습니다.
- 계기·화면의 표시 문구는 별도 관리자 탭에서 수정할 수 있습니다.

검증
- Node.js와 Chromium이 있는 환경에서 npm ci, 서버 실행 후 npm test.
- CHROMIUM_PATH로 Chromium 위치를 지정할 수 있습니다.
- 검사: 자동 재생/자동 입장/4배속/건너뛰기/모션 감소,
  320/390/768/1440px 고정 프레임·좌측 메뉴·본문 스크롤,
  한국 시간대의 시작일/다음 날/시작 전 디데이,
  카테고리·항목·메시지 CRUD와 JSON 내보내기/가져오기,
  실제 테스트 WAV 재생/정지/음량, 음원 누락 오류,
  기존 설정 호환, 사진 업로드, 안전한 문구 표시.
- YouTube 외부 접속이 차단된 개발 환경에서는 실제 스트리밍 대신 로컬 플레이어 대체 응답으로
  링크 해석, 관리자 저장, 임베드 생성/제거와 모바일 배치를 검증합니다. 실제 재생은 배포 환경에서 확인하세요.
- 스크린샷은 artifacts/에 생성됩니다. 실제 음악과 예시 메시지는 테스트에서만 사용됩니다.
