사용 방법
이 편집기는 홈페이지 설정을 만들고 config.json으로 내보냅니다. 다운로드한 파일을 index.html과 같은 위치에 업로드하면 홈페이지가 설정을 불러옵니다. 나루가 별도 JSON 파일 업로드/정적 파일 경로를 지원하지 않으면 이 방식 대신 HTML 안의 설정을 직접 교체해야 합니다. 이 페이지는 비밀번호로 보호된 서버 관리자 기능이 아니라, 정적 홈페이지용 편집 도구입니다.

대문 · VHS TAPE

사진을 고르면 미리보기가 표시됩니다. 이미지 크기에 따라 config.json이 커질 수 있습니다.
IMAGE PREVIEW

0은 흐림 없음, 숫자가 클수록 흐려집니다. OPEN PREVIEW에서 확인해 주세요.

회상 장면 · MEMORY REEL

접속하면 아래 순서대로 자동 재생되고 마지막 장면 뒤 자동 입장합니다. 사진이 없으면 황혼의 필름 화면을 표시합니다. 장면을 모두 지우면 바로 입장합니다.

색상 · CUSTOM PALETTE

색상을 바꾼 뒤 설정 파일을 내보내면 홈페이지에 적용됩니다.

PC 마우스 커서

업로드한 커서는 홈페이지 PC 미리보기에서 확인하세요.

카테고리 · PAGE EDITOR

카테고리를 선택해 제목, 설명, 사진을 수정하세요. 각 카테고리의 구성 유형은 기본 템플릿에 맞춰져 있습니다.

관측소 설정 · WIDGETS

계기 문구, 디데이, 배경음악과 대화 기록을 편집하세요. 저장한 설정은 JSON 내보내기로 공개할 수 있습니다.

공유카드 · SIGNAL POSTCARD

사진과 문구로 1200 × 630 PNG를 만듭니다. 이 도구의 편집 내용은 현재 창에서만 유지되며 config.json에는 포함되지 않습니다.

공유카드 미리보기

내려받은 share-card.png를 나루의 assets/share-card.png에 교체하세요. 공유카드는 config.json과 별도이며, 비밀번호 없이 공개됩니다. SNS에 이미 저장된 카드 이미지는 캐시 때문에 바로 바뀌지 않을 수 있어요.

설정 가져오기 · IMPORT / EXPORT

이전에 저장한 config.json 파일을 불러와 수정할 수 있습니다.

내보낸 설정에는 업로드한 이미지가 포함될 수 있어 파일 크기가 커질 수 있습니다. 사진은 웹용으로 축소한 뒤 사용하는 것을 권장합니다.

아래 JSON은 편집 중인 평문 미리보기입니다. 비공개 내용이 있으면 공유하지 마세요. 다운로드/JSON 복사는 잠금을 적용해 내보냅니다.

주의: 브라우저 저장은 이 기기와 브라우저에만 적용됩니다. 방문자 전체에 공개하려면 내보낸 설정 파일을 홈페이지에 반영해야 합니다.
